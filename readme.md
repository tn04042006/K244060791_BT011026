# 💳 Credit Approval Dashboard

Interactive data visualization dashboard for the Credit Approval dataset from the UCI Machine Learning Repository.

## 📊 Dataset

- Dataset: Credit Approval
- Source: UCI Machine Learning Repository
- Dataset ID: 27
- Number of instances: 690
- Number of variables: 16

The dataset is loaded directly from UCI using the `ucimlrepo` Python package.

## 📈 Visualizations

The dashboard contains:

1. Approval distribution
2. Categorical variable vs approval result
3. Histogram
4. Box plot
5. Scatter plot
6. Missing value analysis
7. Interactive data table

## 🛠️ Technologies

- Python
- Pandas
- Plotly
- Streamlit
- UCI Machine Learning Repository
